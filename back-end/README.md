# Back-end Template

Este é um template base para projetos NestJS.

## Estrutura

- `src/app/example`: Módulo de exemplo com Controller, Service e Module.
- `src/commons`: Infraestrutura base (Banco de dados, Guards, Interceptors, etc.).
- `src/models/dtos/example`: DTO de exemplo.
- `src/models/entities/example`: Entidade de exemplo.

## Como usar

1. Clone o repositório.
2. Configure o arquivo `.env` (use `.env.example` como base).
3. Instale as dependências: `npm install`.
4. Inicie o servidor: `npm run start:dev`.

## Comandos Úteis

- `npm run build`: Compila o projeto.
- `npm run start:dev`: Inicia em modo de desenvolvimento.
- `npm test`: Executa os testes.
